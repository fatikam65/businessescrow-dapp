✨ BusinessEscrow dApp

A decentralized invoice management app on Ethereum Sepolia Testnet — no banks, just smart contracts 💜

---
🌸 What it does
- Create invoices with a reference, payee address & ETH amount
- Pay invoices — ETH transfers directly to the payee
- Look up any invoice by ID to check its status

---

🚀 How to run
1. Open `index.html` in Chrome
2. Switch MetaMask to **Sepolia** test network
3. Click **Connect MetaMask** and you're good to go 🦊
